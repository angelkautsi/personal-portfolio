## About the Project

This is my personal portfolio website, developed to showcase my background, technical skills, projects, and creative work as a Computer Science student and aspiring developer.

The website uses a minimalist design, with a colour pallette consisting of: cream (#F8F5EF), warm beige (#EFE8DC), black (#1A1A1A), muted gold (#A88955), white (#FFFFFF), and soft grey (#777777).

## Website Sections

- **Home:** Introduction and professional identity.
- **About Me:** Educational background, technical skills, interests, and career aspirations.
- **Projects:** A collection of software development projects.
- **Animated Concepts:** Demonstrations of animation techniques incorporated into the website.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## Featured Projects

- **Inventory Control System:** A book inventory application with CRUD operations.
- **Email Sender Application:** An email application supporting inbox retrieval and email sending.
- **IT Ticketing System:** A system designed to manage IT support tickets.
- **MAMA+:** An AI-enhanced maternal care support system.

## Animations

The website demonstrates three animation concepts:

1. Typing effect.
2. Interactive hover animations.
3. Image zoom on hover.

## Running the Website Locally

1. Clone this repository: https://github.com/angelkautsi/personal-portfolio.git
2. Open the project folder in your preferred code editor.
3. Open `index.html` in a web browser.
